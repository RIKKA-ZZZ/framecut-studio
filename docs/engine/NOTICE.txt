Framecut uses the single-threaded UMD binary distribution of @ffmpeg/core 0.12.10.
The package is licensed under GPL-2.0-or-later. See COPYING.GPLv2.
The JavaScript loader and WebAssembly executable are unmodified. For static hosting,
the executable is split into four binary files and reassembled before instantiation.
